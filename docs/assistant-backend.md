# ИИ-ассистент: как всё устроено

## Что было на старом сайте
Файл `js/main.js` на ydenisa.ru:

```js
fetch('/api/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ message, sessionId: chatSessionId }),
});
// ответ: data.reply (текст), data.sessionId (сохраняется в памяти)
```

- ограничение ввода — 500 символов;
- при сетевой ошибке — локальные ответы (график / адрес / телефон / приветствие);
- при ответе с ошибкой — `data.reply || 'Произошла ошибка. Позвоните нам…'`.
- Модель, ключи и стриминг на фронтенде не видны — это всё на сервере (`/backend/` закрыт в robots.txt).
  Стриминга не было: ответ приходит одним JSON.

## Что сейчас
`src/js/services/assistant.js` — **тот же протокол без изменений**:

```
POST /api/chat   { "message": "...", "sessionId": "..." | null }
→                { "reply": "...", "sessionId": "..." }
```

Отличия только в интерфейсе и надёжности:
- `sessionId` хранится в `sessionStorage` — диалог не теряется при перезагрузке вкладки;
- таймаут 25 с (AbortController);
- если сервер недоступен / ответил ошибкой — отвечает **локальный справочник** `src/js/services/knowledge.js`
  строго по данным `src/data/business.js` (цены, график, адрес). Чего нет в данных — «Точной информации у меня нет…»;
- к любому ответу (и серверному, и локальному) добавляются кнопки: «Показать в прайсе», «Позвонить», «Маршрут».

## Настройка endpoint
Одна переменная при сборке:

```bash
ASSISTANT_ENDPOINT=/api/chat npm run build          # по умолчанию
ASSISTANT_ENDPOINT=https://ai.example.ru/chat npm run build
ASSISTANT_ENDPOINT=off npm run build                # только локальный справочник
```

Значение попадает в `<meta name="yd-assistant-endpoint">` в `dist/index.html` — его можно поменять и вручную.
Для другого домена бэкенд должен отдавать CORS-заголовки.

## Чтобы ИИ не придумывал цены
При каждой сборке создаётся `dist/assistant-knowledge.json` — актуальные услуги, цены, график и адрес из
`src/data/business.js`. Рекомендуется, чтобы бэкенд подставлял этот файл в системный промпт, например:

> Ты — консультант «Шиномонтажа у Дениса» (Сарапул). Отвечай только по данным ниже.
> Если ответа в данных нет — скажи «Точной информации у меня нет, лучше уточнить у мастера по телефону
> +7 (950) 172-55-14». Не называй цены, которых нет в данных. Все цены «от» — окончательную стоимость
> называет мастер. Данные: {{assistant-knowledge.json}}

Ключи API хранятся только на сервере (переменные окружения бэкенда). Во фронтенде ключей нет.

## Локальная проверка протокола
```bash
node scripts/mock-api.mjs                         # заглушка на :3001
API_PROXY=http://127.0.0.1:3001 npm run dev       # сайт на :5173, /api → заглушка
API_PROXY=http://127.0.0.1:3000 npm run dev       # или ваш настоящий бэкенд
```
