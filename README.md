# Шиномонтаж у Дениса — новый сайт

Полная переработка ydenisa.ru. Концепция — **«ОДИН ОБОРОТ»**: вся страница — это один оборот колеса
(лимб внизу слева показывает 000°→360°). В центре — настоящее 3D-колесо на собственном WebGL-движке:
с протектором, надписями на боковине (название, адрес, график), литым или штампованным диском,
тормозным диском, суппортом и честным размытием вращения. Прокрутка — это режиссура:

| Сцена | Что происходит |
|---|---|
| 00 Старт | «Накачка» колеса (загрузчик), колесо въезжает и «выправляет» кривые буквы «ДЕЛАЕМ КРУГЛОЕ РОВНЫМ.». Колесо крутится мышью/пальцем, наклоняется к курсору, ценники привязаны к точкам 3D-колеса |
| 01 Анатомия | Камера облетает колесо: протектор с гвоздём → грыжа на боковине → погнутый обод выпрямляется → дисбаланс «бьёт» и затухает → шипы → колесо разворачивается в велосипедное. Каждый шаг — с ценами из прайса |
| 02 Цены | Оранжевая «диафрагма» из колеса. Колесо = поворотный селектор услуг; диаметр R13→R19 меняет посадку диска, «штамповка» показывает штампованный диск, цифры прокручиваются как одометр |
| 03 Мастерская | Нырок сквозь ступицу; реальные фото собраны в барабан-«протектор», прокрутка его вращает |
| 04 Пробег | Приборная панель: стрелки «15 000+ авто», «500+ велосипедов», лампы «почему выбирают нас»; отзывы дрейфуют |
| 05 ИИ | Вопросы вращаются по орбите вокруг колеса |
| 06 Контакты | Колесо укатывается и оставляет след протектора; телефон «въезжает» цифрами; карта, график, FAQ |

Между сценами через экран проходят огромные слова, фон меняется «диафрагмой» из центра колеса.
ИИ-ассистент живёт в углу: глаз следит за курсором, в нужных сценах сам предлагает помощь
(«Назовите диаметр — скажу цену», «Проложить маршрут?»), чат раскрывается диафрагмой.

При этом всё содержимое — цены, телефон, адрес, график, отзывы — лежит в обычном HTML и доступно
без JS, с клавиатуры и с `prefers-reduced-motion`. Без WebGL показывается SVG-колесо.

- Статический сайт, **ноль npm-зависимостей** (нужен только Node ≥ 18 для сборки), WebGL — свой (~600 строк, без three.js).
- Все данные компании — в одном файле `src/data/business.js`.
- Протокол ИИ-ассистента сохранён 1-в-1 (`POST /api/chat`).

## 1. Запуск локально

```bash
npm run build      # собрать dist/ и preview.html
npm run preview    # http://localhost:5173
npm run dev        # то же + автопересборка при изменениях в src/ и public/
npm test           # проверка: цены, телефон, якоря, JSON-LD, ответы ИИ-справочника
```

Без Node: просто откройте **`preview.html`** — это весь сайт в одном файле (шрифты, стили, скрипты внутри;
фото подтягиваются с ydenisa.ru, Метрика отключена). ИИ в нём отвечает по локальному справочнику.

Проверить связку с настоящим ИИ-бэкендом:

```bash
API_PROXY=http://127.0.0.1:3000 npm run dev   # /api/* уйдёт на ваш бэкенд
node scripts/mock-api.mjs                     # или заглушка на :3001 для проверки протокола
```

## 2. Production-сборка

```bash
npm run build
```

Результат — папка **`dist/`**. Это **готовый корень сайта** — ровно то, что лежит сейчас
в `/var/www/ydenisa.ru` на сервере, только с новым фронтендом:

```
dist/
  index.html                  страница (весь контент в HTML — хорошо для SEO и без JS), Метрика 106113716
  assets/app.<hash>.css       стили (~16 KB gzip)
  assets/app.<hash>.js        скрипты + WebGL-движок (~40 KB gzip)
  fonts/*.woff                Inter / Inter Display / YD Mono, только латиница+кириллица
  images/gallery/shop-1…6.jpg реальные фото мастерской (из старого репозитория)
  images/favicon/*, favicon.ico, site.webmanifest   иконки старого сайта
  images/og-image.jpg         картинка для соцсетей/мессенджеров 1200×630 (на старом сайте её не было)
  googleab543badaa364955.html подтверждение Google Search Console
  robots.txt, sitemap.xml
  assistant-knowledge.json    цены сайта для системного промпта ИИ (nginx его наружу не отдаёт)
  backend/                    бэкенд ИИ (Express + OpenRouter) — СТАРЫЙ, без изменений
  backend/.env.example        шаблон настроек ИИ (сам .env в архив не входит)
  package.json, package-lock.json   зависимости бэкенда (как в старом репозитории)
```

Готовый `dist/` уже лежит в архиве — собирать заново нужно только после правок в `src/`.

## 3. Деплой на VPS вместо старого сайта

Схема сервера не меняется: nginx отдаёт статику из `/var/www/ydenisa.ru` и проксирует `/api/` на
Node (порт 3000), Node запускается из той же папки командой `node backend/app.js`.
Конфиг nginx менять **не нужно** — копия текущего лежит в `deploy/nginx.conf`.

```bash
# 0) на сервере: резервная копия старого сайта (вместе с backend/.env)
sudo cp -a /var/www/ydenisa.ru /var/www/ydenisa.ru.bak-$(date +%F)

# 1) со своего компьютера: залить новый сайт.
#    --delete уберёт старые css/ и js/; .env, node_modules и логи НЕ трогаются.
rsync -avz --delete \
  --exclude 'backend/.env' --exclude 'node_modules/' --exclude '*.log' \
  dist/ user@server:/var/www/ydenisa.ru/

# 2) на сервере: зависимости бэкенда (если папки node_modules ещё нет)
cd /var/www/ydenisa.ru && npm ci --omit=dev

# 3) ключ ИИ: если backend/.env уже был — он остался на месте.
#    Если сервер новый: cp backend/.env.example backend/.env && nano backend/.env

# 4) перезапуск Node — тем же способом, что и раньше, например:
pm2 restart all            # или: sudo systemctl restart <ваш-сервис>
sudo nginx -t && sudo systemctl reload nginx
```

Без rsync (например, через панель/FTP): загрузите **содержимое** папки `dist/` в `/var/www/ydenisa.ru/`,
поверх старого; старые папки `css/` и `js/` можно удалить; файл `backend/.env` не трогайте.

**Проверка после выкладки:**

- `https://ydenisa.ru/` — новый сайт; Ctrl+F5, если браузер показывает старый;
- `https://ydenisa.ru/api/health` → `{"status":"ok","aiEnabled":true,…}`;
- в чате ИИ спросить «Сколько стоит переобуть R16?»;
- `https://ydenisa.ru/backend/.env` и `/assistant-knowledge.json` → 404 (закрыто nginx).

Откат: `sudo rm -rf /var/www/ydenisa.ru && sudo mv /var/www/ydenisa.ru.bak-<дата> /var/www/ydenisa.ru`.

Если ИИ-ключа нет или OpenRouter недоступен — сайт не ломается: бэкенд отвечает заглушкой,
а если не отвечает сам бэкенд, ассистент на сайте отвечает по локальному справочнику цен.

## 4. Где данные компании

**`src/data/business.js`** — единый источник. Из него собираются: все блоки страницы, прайс, FAQ,
schema.org (LocalBusiness/AutoRepair + FAQPage), sitemap, локальный справочник ИИ и `assistant-knowledge.json`.

| Что поменять | Где в `business.js` |
|---|---|
| **Цены** | `services[].prices[]` — `amount` (число), `from: true` = «от», `text` — для «бесплатно / договорная / уточняет мастер» |
| **Телефон** | `phone` — `display`, `compact`, `href` (`tel:+7…`), `e164` |
| **Адрес** | `address` + `geo` (координаты) + `links.yandexRoute` |
| **График** | `hours` — `open`, `close`, `workdays` (1=Пн … 6=Сб, 0=Вс), тексты `text`, `dayOff`, `short` |
| Отзывы | `reviews[]` |
| Фото и подписи | `photos[]` |
| Симптомы «Что случилось?» | `symptoms[]` |
| SEO-тексты, title, description | `seo` |

После правки — `npm run build` и выкладка `dist/`.

Тексты ИИ-интерфейса (приветствие, быстрые вопросы) — `src/data/assistant.js`.

## 5. ИИ-интеграция

- Адаптер: **`src/js/services/assistant.js`** — протокол старого сайта:
  `POST /api/chat {message, sessionId}` → `{reply, sessionId}`.
- Локальный справочник (если сервер недоступен): `src/js/services/knowledge.js`.
- Интерфейс: `src/js/components/chat.js`, стили `src/styles/ask.css`.
- Бэкенд: `server/backend/` (копия старого, в сборке → `dist/backend/`). Модель, ключ, CORS — в `backend/.env`.
- Подробно, включая рекомендуемый системный промпт: `docs/assistant-backend.md`.

## 6. Переменные окружения

**Бэкенд ИИ** — файл `backend/.env` на сервере (шаблон `backend/.env.example`). Ключей в архиве нет.

| Переменная | Пример | Назначение |
|---|---|---|
| `OPENROUTER_API_KEY` | — | ключ OpenRouter. Без него ИИ отвечает заглушкой |
| `OPENROUTER_MODEL` | `openrouter/free` | модель (можно несколько через запятую); старое имя `AI_MODEL` тоже работает |
| `OPENROUTER_FALLBACK_MODEL` | — | резервные модели |
| `OPENROUTER_APP_TITLE` | `Шиномонтаж у Дениса` | заголовок для OpenRouter |
| `ALLOWED_ORIGIN` | `https://ydenisa.ru` | CORS и HTTP-Referer |
| `PORT` | `3000` | порт Node (его ждёт nginx в `proxy_pass`) |

Внимание: бэкенд читает именно `backend/.env` (а не `.env` в корне, как написано в старом README).

**Сборка фронтенда** — все необязательные, секретов во фронтенде нет:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `ASSISTANT_ENDPOINT` | `/api/chat` | адрес ИИ-бэкенда. `off` — только локальный справочник |
| `SITE_URL` | `https://ydenisa.ru/` | canonical, og:url, sitemap |
| `PORT` | `5173` | порт `npm run dev/preview` |
| `API_PROXY` | — | куда `npm run dev` проксирует `/api/*` (например `http://127.0.0.1:3000`) |

## 7. Структура

```
server/        бэкенд ИИ со старого сайта (без изменений) + его package.json
public/        фото, иконки, шрифты — копируются в dist/ как есть
src/
  data/          business.js (данные), scenes.js (сценарий «анатомии», слова-переходы), assistant.js (тексты ИИ)
  templates/     HTML-шаблоны (выполняются при сборке → статический HTML)
    scenes/      chrome (сцена, шапка, лимб, загрузчик, меню), hero, anatomy, prices, works, mileage, ask (+ИИ-док), finish (+подвал)
  js/
    main.js      точка входа
    gl/          stage.js (3D-колесо), geometry.js (профили шины/диска, спицы), shaders.js, math.js
    core/        runtime.js (единый цикл кадров), director.js (ключевые кадры колеса по прокрутке, заливки, слова)
    scenes/      boot (WebGL, загрузчик, въезд, захват колеса), hero, anatomy, prices, works, mileage, ask-finish, chrome (лимб, меню, курсор, магнитные кнопки)
    components/  chat.js (ИИ: интерфейс, глаз, подсказки), status.js, media.js, reveal.js, wheel-svg.js (SVG-колесо для запасного режима)
    services/    assistant.js (сервер), knowledge.js (справочник)
  styles/        tokens → base → stage → chrome → сцены; index.css задаёт порядок
```

**Где менять режиссуру:** положения, масштаб и ракурсы колеса для каждой сцены — объект `SCENES`
в `src/js/core/director.js`; цвета фонов сцен — `BG` там же.

## 8. Производительность, SEO, доступность

- Один `requestAnimationFrame` на весь сайт; колесо перерисовывается только когда что-то меняется.
- WebGL: DPR ограничен (1.75 desktop / 1.5 телефон), при просадке кадров разрешение снижается автоматически.
  Геометрия ~40 тыс. вершин, одна текстура (надписи боковины). Без WebGL — SVG-колесо, без JS — обычная страница.
- `prefers-reduced-motion`: нет загрузчика, въезда, холостого вращения, размытия, кинетики букв;
  барабан фото превращается в сетку; переходы мгновенные.
- Весь текст и цены — в статическом HTML. schema.org `AutoRepair` + `FAQPage`, canonical, OG, geo-meta,
  yandex-verification сохранены; старые якоря `#services #works #reviews #about #contacts` работают.
- Семантика: один `h1`, вкладки услуг с ARIA и стрелками, ловушка фокуса в меню, Esc закрывает
  чат/меню/лайтбокс, видимые focus-состояния.
- Тестовый режим для медленных машин: `?lowgl` в адресе — колесо рендерится в пониженном разрешении.

## 9. Шрифты и лицензии

Inter и Inter Display (SIL OFL 1.1) и YD Mono — субсет Liberation Mono (SIL OFL 1.1, переименован
согласно условиям Reserved Font Name). Тексты лицензий — `public/fonts/LICENSE-*.txt`.
Пересобрать субсеты: `python3 scripts/subset-fonts.py` (нужен fontTools).
